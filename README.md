# 100 Days of AI/ML System Design

A 100-day deep dive into production-grade AI/ML system design—from problem
formulation and ML modeling to scalable architectures, optimization,
evaluation, and trade-offs.

The objective is to understand why a system is designed a certain way, not
just to memorize architectures.
